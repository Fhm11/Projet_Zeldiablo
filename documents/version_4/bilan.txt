État de l'application :
Le jeu Zeldiablo est fonctionnel. Voici les nouvelles fonctionnalités faites depuis la version 3:

Apparition d'une amulette :
Une amulette apparaît à une position précise, elle ne peut apparaître sur un mur et le héros et les monstres peuvent passer sur sa case.

Ramassage de l'amulette :
Le héros peut ramasser l'amulette en passant sur sa case, les monstres ne peuvent pas la récupérer.

Fin du jeu avec l'amulette :
Quand le joueur retourne à sa position de base, il gagne la partie et le jeu se ferme.

Patron Stratégie pour les attaques de monstres :
Nous avons créé un patron stratégie car les monstres ont 2 attaques, une attaque normale et une attaque critique. Comme les deux classes d'attaques possèdent le même code, nous avons fait le patron stratégie. Ainsi le code n'est pas dupliqué en fonction de l'attaque utilisé.

Tous les tests unitaires des fonctionnalités sont réussis.

Difficultés rencontrées :
Nous n'avons pas rencontrés de difficultés sur ces fonctionnalités.
